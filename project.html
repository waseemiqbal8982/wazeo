1. Overview

Wazeo is a premium SMM panel (Instagram / TikTok / YouTube) built with Next.js 16 (App Router) + TypeScript + Tailwind v4 + Supabase + Framer Motion + Chart.js. Supports gradual/organic delivery, admin panel, access keys, multi-language (en/ur/hi/fr/zh), themes, currency switching.

2. Architecture

  • Frontend: app/ components/ (App Router; server + client components; shared ui/)
  • Backend: app/api/** route handlers (Node); server actions
  • Data: Supabase (Postgres) — all tables have RLS; service-role client server-only
  • Auth: Supabase Auth (email/password, OTP, access-key redeem); admin allowlist ADMIN_EMAILS; admin PIN
  • Delivery engine: lib/organic/ (curve → micro-step plan); lib/schedule.ts; cron /api/cron/process
  • External: SMM provider (provider.ts, mock fallback); Mercury AI (lib/ai.ts, fallback)
  • Deploy: Vercel (production https://innvera.shop) + GitHub Actions cron
